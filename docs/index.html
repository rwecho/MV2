MV2

A modern V2EX client.

一个现代、开源、面向移动端重新设计的 V2EX 第三方客户端。当前版本使用 Flutter 构建，支持 iOS 与 Android。

FlutteriOSAndroidOpen Source

现代浏览体验

首页 Tab、节点、主题详情、成员页与通知体验针对手机重新设计，而不是简单套壳网页。

完整社区交互

支持登录、回复、引用、感谢、发布主题、通知与 V2EX 原生交互能力。

原生移动能力

深浅主题、触感反馈、下拉刷新、Deep Link、推送通知与 iOS Widget 等移动端能力。

MV2

MV2 是产品品牌，不再代表任何特定技术框架。品牌内部概念为 Matrix for V2EX：红与蓝代表选择与入口，V2 指向 V2EX。项目与 V2EX 官方无隶属或背书关系。
